# SlozOS Pro

A beginner-friendly desktop OS for work and play, designed like Windows 11 and built on [Zorin OS](https://zorin.com/os/) Core (Ubuntu 24.04 LTS).

**Status:** in development. The first release will be SlozOS Pro 1.0.
